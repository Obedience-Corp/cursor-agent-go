# Security policy

## Supported versions

Security fixes are applied to the latest released SDK version and `main`. The
runtime compatibility target is declared by `cursor.TestedAgentVersion`.

## Reporting a vulnerability

Email **security@obediencecorp.com**. If GitHub private vulnerability reporting
is enabled for the repository, that is also an accepted channel. Do not open a
public issue for a suspected vulnerability or include credentials, private
source code, or raw Cursor session data in a report.

Include the affected SDK and `cursor-agent` versions, operating system, impact,
and a minimal reproduction with secrets and personal metadata removed.
Maintainers will acknowledge the report, assess severity, and coordinate
remediation and disclosure through the private advisory.
