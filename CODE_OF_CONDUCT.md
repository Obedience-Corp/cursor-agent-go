# Code of conduct

We are committed to a respectful, harassment-free community for everyone,
regardless of identity, background, experience, or viewpoint.

Be constructive, assume good intent, respect boundaries, and focus criticism on
ideas and code rather than people. Harassment, threats, discrimination,
doxxing, and sustained disruption are not acceptable in project spaces.

Maintainers may edit or remove contributions and restrict participation when
behavior harms the community. Report conduct concerns privately to
conduct@obediencecorp.com. Reports will be handled as confidentially as
practical, with conflicts of interest avoided where possible.

By participating, you agree to follow this code in repository discussions,
reviews, issues, and other project spaces.
